# Автоматическая проверка орфографии и грамматики русского текста

Курсовая работа: консольное приложение на языке **C**, которое проверяет русскоязычный текст на орфографические и грамматические ошибки, а также подбирает варианты исправления для слов, которых нет в словаре.

---

## Назначение проекта

Программа предназначена для автоматической проверки правописания текстов на русском языке. Основные задачи:

- обнаружение **орфографических** ошибок (слов, отсутствующих в словаре);
- обнаружение **базовых грамматических** ошибок (нарушение согласования в паре «прилагательное + существительное» и «существительное + глагол в прошедшем времени»);
- подбор вариантов исправления для орфографических ошибок.

В качестве источника морфологической информации используется открытый словарь **OpenCorpora** в формате XML.

---

## Возможности

1. Загрузка и парсинг морфологического словаря OpenCorpora (XML), извлечение словоформ и граммем.
2. Построение сбалансированного двоичного дерева поиска для хранения словоформ.
3. Построение массива триграмм (`34 × 34 × 34 = 39304` элемента) для быстрого отбора слов-кандидатов.
4. Токенизация входного текста (разбиение на слова с учётом UTF-8, дефисов и разделителей).
5. Проверка орфографии — бинарный поиск каждого токена в дереве.
6. Проверка грамматики:
   - согласование прилагательного с существительным по роду, числу и падежу;
   - согласование существительного в именительном падеже с глаголом в прошедшем времени по роду и числу.
7. Генерация исправлений на основе расстояния **Дамерау — Левенштейна** (с учётом транспозиции соседних символов).
8. Вывод отчёта в консоль и запись в текстовый файл `RESULT.txt`.
9. Обработка ошибок: отсутствие словаря, повреждённый файл, пустой словарь, ошибки выделения памяти.

## Алгоритм работы

### Математическая модель орфографической проверки

Для слова `w` и словаря `D` определяется, принадлежит ли `w` множеству `D`. Если нет — ищутся ближайшие по метрике слова из `D`.

В качестве метрики выбрано **расстояние Дамерау — Левенштейна**. Это расширение классического расстояния Левенштейна: помимо вставки, удаления и замены символа добавлена операция **перестановки двух соседних символов**. По исследованиям Дамерау, около 80% реальных опечаток относятся как раз к этим четырём типам.

### Модель грамматической проверки

Каждой словоформе в словаре OpenCorpora сопоставлен набор **граммем** (часть речи, род, число, падеж, время и др.). Для проверки согласования анализируются пары рядом стоящих слов:

- **прилагательное + существительное** — совпадение рода, числа и падежа;
- **существительное (им. падеж) + глагол (прош. время)** — совпадение рода и числа.

Если ни одна комбинация граммем не даёт совпадения — фиксируется грамматическая ошибка.

### Подбор исправлений

Для каждого слова, не найденного в словаре:

1. слово дополняется пробелами по краям, выделяются все триграммы;
2. по индексу каждой триграммы из массива извлекается цепочка узлов дерева (связный список);
3. для каждого узла-кандидата вычисляется расстояние Дамерау — Левенштейна до исходного слова;
4. кандидаты сортируются по возрастанию расстояния;
5. в отчёт попадают первые `MAX_COUNT_CORRECTIONS` (по умолчанию 7) слов с расстоянием не более `MAX_DISTANCE`.

## Сборка и запуск

- GCC (MinGW для Windows)

### Windows (MinGW)

```bash
gcc *.c -o orphographia.exe
orphographia.exe
```

### Linux / macOS

```bash
gcc *.c -o orphographia
./orphographia
```

## Использование

При запуске программа:

1. Загружает XML-словарь, строит временный массив, сортирует его, строит сбалансированное дерево, создаёт массив триграмм.
2. Создаёт выходной файл `RESULT.txt`.
3. Предлагает меню:

```text
=============================
ВЫБОР РЕЖИМА ВВОДА ТЕКСТА
1 - Ввод текста из консоли...
2 - Ввод текста из файла...
666 - Завершить...
```

Для ввода текста из консоли введите `1` и текст. Для чтения из файла — `2` и путь к файлу. Для завершения — `666`.

### Пример вывода (отчёт)

```text
===========================================
РЕЗУЛЬТАТЫ ПРОВЕРКИ ПРАВОПИСАНИЯ ТЕКСТА!
Некорректное слово 1: гластук
Варианты исправлений:
1. галстук
2. пласту
3. пластик
...

Грамматическая ошибка 1: холодными вагоном

ИТОГО:
Орфографические ошибки: 1
Грамматические ошибки: 1
===========================================
```

## Тестирование

В ходе работы было выполнено 8 тестов:

| № | Что проверяется | Результат |
|---|-----------------|-----------|
| 1 | Текст без русских букв | корректно, ошибок нет |
| 2 | Отсутствие XML-файла словаря | корректная обработка ошибки |
| 3 | Разный регистр, знаки препинания, цифры | корректная токенизация |
| 4 | Орфографические ошибки (8 типов опечаток) | все найдены, исправления подобраны |
| 5 | Согласование «прил. + сущ.» | 4 из 5 ошибок найдены |

Подробное описание каждого теста, входные данные и результаты приведены в пояснительной записке (раздел 5).

## Известные особенности

- Анализируются только два типа синтаксических связей: «прил. + сущ.» и «сущ. + глаг. в прош. времени».
- Местоимения не проверяются на согласование с глаголами.
- Если между существительным и глаголом стоит другое слово (например, частица «не»), согласование не проверяется.
- При нескольких подряд идущих прилагательных проверка идёт только для соседних с существительным слов.
- Не проверяется пунктуация и стилистика.
- Не обрабатываются сложные синтаксические конструкции.
- Слова очень маленькой длины (1–2 символа) могут не находиться в словаре и помечаться как ошибки.
